# Python Artificial Intelligence Lab (Fall 2025)

Comprehensive repository of practical laboratory projects, implementations, and experiments covering Classical Artificial Intelligence, Machine Learning, Computer Vision, and AI-powered web applications.

## Coursework & Laboratory Directory

| Lab Module | Domain / Focus | Key Technologies | Description |
| :--- | :--- | :--- | :--- |
| **Lab 1** | Web Data Extraction | Python, Requests, BeautifulSoup, Flask | Automated email scraping utility with tabular Excel export and web dashboard. |
| **Lab 2** | Predictive Analytics | Pandas, Scikit-learn, Jupyter | End-to-end classification pipeline on tabular clinical data. |
| **Lab 3** | Uninformed Search | Python, Jupyter | State-space graph exploration solving the classic Water Jug Problem via DFS. |
| **Lab 4** | Game AI | Python, Jupyter | Adversarial and heuristic search techniques applied to board games. |
| **Lab 5** | Search Strategies | Python, Jupyter | Comparative analysis of pathfinding algorithms and heuristics. |
| **Lab 6** | Computer Vision | OpenCV, Haar Cascades, Flask | Real-time face detection web interface with pre-trained Haar classifiers. |
| **Lab 7** | Interactive AI | Flask, HTML5 | Dynamic web application implementing rule-based agent logic. |
| **Lab 8** | Web Systems | Flask, CSS3 | Form-based interactive user interface for AI inference. |
| **Lab 9** | Exploratory ML | Scikit-learn, Seaborn | Data exploration, feature scaling, and correlation analysis. |
| **Lab 10** | Conversational Agents | Flask, Rule Engines | FitnessBot: Automated conversational health guidance bot. |
| **Lab 11** | Supervised Learning | Scikit-learn, Matplotlib | Model training, cross-validation, and performance evaluation. |
| **Lab 12** | Full-Stack Health Bot | Flask, Custom CSS | Enhanced FitnessBot with responsive modern interface. |
| **Lab 13** | LLM Applications | Flask, Groq API, LLaMA 3.1 | AI-powered technical interview preparation and scoring system. |

## Prerequisites & Setup
1. Python 3.10+
2. Install common dependencies:
```bash
pip install flask pandas numpy scikit-learn opencv-python jupyter groq
```

## Running Labs
Each laboratory directory is self-contained. Navigate to any lab directory and execute the respective script or launch Jupyter:
```bash
cd "Lab 6"
python app.py
```
